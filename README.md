# Code-Aware Refactoring Workflow Planner

## Project Overview

This project aims to develop a code-aware refactoring workflow
planner for Java systems.

The system will detect code smells, analyze software metrics
and dependencies, prioritize refactoring actions based on
developer-selected quality goals, and provide explainable
step-by-step guidance.

## Technology Stack

- Java 21
- Maven
- IntelliJ IDEA
- PMD
- CK Tool
- JavaParser
- JUnit

## Project Structure

- src/main/java: Application source code
- src/test/java: Automated tests
- config: Tool and application configuration
- docs: Technical documentation
- sample-projects: Sample Java projects
- test-data: Smell and clean-code test fixtures
- results: Generated reports and evaluation results
